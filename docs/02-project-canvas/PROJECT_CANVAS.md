# Problem Statement

Space mission operators, engineers, researchers, and educators face significant challenges in understanding large volumes of technical space-related information.

Current workflows require manual analysis of technical documents, satellite reports, mission logs, and scientific publications, making decision-making slower and more difficult.

---

# Proposed Solution

Aegis AI is an intelligent mission decision support platform powered by IBM Granite foundation models.

The system combines Retrieval-Augmented Generation (RAG), AI reasoning, and interactive visualisation to transform technical space knowledge into clear, explainable, and actionable recommendations.
