# User Stories

## Epic 1 — AI Mission Assistant

### US-001

As a Mission Planner,

I want to ask natural language questions about mission documentation,

So that I can make faster and more informed decisions.

- The user can submit a question.

- The AI understands the request.

- Relevant documents are retrieved.

- IBM Granite generates an answer.

- Sources are displayed.

- Response time is acceptable.

### US-002

As an Aerospace Engineer,

I want AI to summarise technical reports,

So that I can quickly understand engineering findings.

- Upload document

- AI summarises content

- Key findings extracted

- Risks identified

- Summary downloadable

### US-003

As a Researcher,

I want semantic search across mission knowledge,

So that I can discover relevant information rapidly.

### US-004

As a Student,

I want AI to explain complex aerospace concepts,

So that I can learn more effectively.

### US-005

As a User,

I want to view previous AI conversations,

So that I can revisit earlier analyses.

### US-006

As a Mission Planner,

I want AI-generated mission recommendations,

So that I can evaluate possible actions.

### US-007

As an Engineer,

I want visual dashboards,

So that I can understand mission status quickly.
