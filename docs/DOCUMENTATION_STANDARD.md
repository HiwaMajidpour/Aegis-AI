# Documentation Standard

## Purpose

This document defines the documentation standards used across the Aegis AI project.

The goal is to ensure consistency, maintainability, readability, and research readiness across all project documents.

---

# General Rules

- All documentation must be written in English.
- All code comments must be written in English.
- Every document must have version control metadata.
- Every architectural decision must be documented.
- Documentation must be updated before implementation.
- Documents should be concise, clear, and actionable.

---

# Document Header

Every document must begin with:

---
Title:
Version:
Status:
Author:
Last Updated:
Classification:
Review Cycle:
---

Example:

---
Title: Project Charter
Version: 1.0.0
Status: Approved
Author: Hiwa Majidpour
Last Updated: YYYY-MM-DD
Classification: Public
Review Cycle: Monthly
---

# Definition of Done

A document is considered complete only if:

- Metadata exists.
- Version is assigned.
- Status is assigned.
- Sections are complete.
- Grammar has been reviewed.
- Formatting is consistent.
- Diagrams are included when required.
- Commit message follows conventions.
